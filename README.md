## 🛠️ 安裝教學 | Installation Guide

### 繁體中文

1. **下載錶盤檔案**：
   - 點擊上方表格中的下載連結，獲取 [`wf_design.bin`](./wf_design.bin) 檔案。
2. **傳輸至手機**：
   - 將下載好的 `.bin` 檔案存放在手機的儲存空間中。
3. **使用第三方管理工具同步**：
   - 開啟支援自訂錶盤安裝的應用程式（例如 **Notify for Xiaomi**、**Mi Fitness (自訂版/開發者模式)** 或其他相容的錶盤同步工具）。
   - 確認手機與小米手錶已透過藍牙正常連線。
   - 在應用程式中選擇「自訂錶盤 / 安裝第三方錶盤 (Custom Watch Face)」，並選取下載的 `.bin` 檔案。
4. **完成同步**：
   - 等待傳輸進度完成，手錶即可自動切換至新錶盤。

---

### English

1. **Download the File**:
   - Click the download link above to download [`wf_design.bin`](./wf_design.bin).
2. **Transfer to Mobile Device**:
   - Save or move the `.bin` file to your smartphone storage.
3. **Sync to Xiaomi Watch**:
   - Open a compatible management tool (such as **Notify for Xiaomi**, modified **Mi Fitness**, or other watch face sync apps).
   - Ensure your Xiaomi Watch is paired and connected via Bluetooth.
   - Navigate to the **Custom Watch Face** / **Install local watch face** section and select the downloaded `.bin` file.
4. **Complete Installation**:
   - Wait for the synchronization process to finish. The watch will automatically apply the new face.
