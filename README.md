🛠 How to Install

Download the File: Click on the wf_design.bin link above and download the raw file.

Transfer: Move the .bin file to your smartphone.

Sync to Watch:

Use a compatible management app (such as Notify for Xiaomi or other watch face sync tools).

Ensure your Xiaomi Watch is connected via Bluetooth.

Select the "Custom Watch Face" option in the app and upload the downloaded .bin file.

Wait for the synchronization to finish.
